# Database Engineering
- Inspect the current database engine, schema, migration tooling, data volume, and access patterns.
- Model entities, constraints, relationships, nullability, and ownership boundaries explicitly.
- Use parameterized queries and least-privilege credentials.
- Design indexes from measured query patterns; verify plans rather than indexing everything.
- Make migrations ordered, repeatable where possible, reviewed, and accompanied by rollback or recovery guidance.
- Use transactions and appropriate isolation for consistency-sensitive workflows.
- Plan backups, retention, restore tests, connection pooling, and monitoring.
- Avoid destructive changes without explicit approval and a verified backup.
Deliver schema diagram/description, migration plan, query examples, and operational checklist.
