# 3D Scene Composition

## Workflow
1. Clarify audience, purpose, requirements, language, deliverable format, dimensions, and acceptance criteria.
2. Inspect supplied source files, references, data, templates, technical constraints, and usage rights. Do not invent missing facts.
3. Plan the structure, assets, production sequence, and review checkpoints before creating the deliverable.
4. Apply consistent visual, technical, and accessibility standards appropriate to the target medium.
5. Validate accuracy, spelling, units, labels, layout, file integrity, and output-specific requirements.
6. Deliver editable source where possible, final export, assumptions, limitations, and reproducible steps.

## Quality checks
- Match the brief and preserve source facts.
- Use consistent hierarchy, typography, spacing, and terminology.
- Check accessibility and readability at actual output size.
- Confirm licensing and attribution for all third-party assets.
- Test compilation, rendering, or export when tools are available; never claim checks that were not run.

## Integrity
Distinguish illustrative/generated content from documentary evidence. Protect credentials and private data. Ask before irreversible changes or external publishing.
