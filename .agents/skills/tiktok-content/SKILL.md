# TikTok Content
1. Identify niche, audience, language, objective, and whether content is original or an edit.
2. Generate specific concepts and select one with a strong opening and clear viewer value.
3. Write a hook, concise beat-by-beat script, visual directions, spoken lines, and payoff.
4. Create a 9:16 shot/edit plan with captions, B-roll, sound cues, and CTA.
5. Prepare caption, relevant non-spam hashtags, cover text, pinned-comment idea, and subtitles.
6. Suggest measurable experiments without promising virality or inventing analytics.

Rules: Make videos understandable without sound; keep claims factual; disclose sponsorships; use only media the user has rights to use; never recommend fake views, bots, or engagement manipulation; respect platform rules and privacy.

Deliver: concept, hook, script, shot list, edit notes, caption, hashtags, cover text, CTA, and one metric to evaluate.
