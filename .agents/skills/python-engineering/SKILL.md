# Python Engineering
- Inspect Python version, project layout, dependency manager, linting, and test conventions.
- Prefer clear modules, type hints, small functions, and explicit interfaces.
- Handle errors intentionally; do not swallow exceptions or log secrets.
- Use virtual environments and pinned or constrained dependencies as appropriate.
- Validate inputs, use pathlib for paths, and manage resources with context managers.
- Add unit tests for normal, boundary, and failure behavior.
- Run formatter, linter, type checker, tests, and package/build checks when available.
Deliver maintainable code, usage examples, dependency notes, and actual verification results.
