# Image Generation Art Direction
- Clarify the intended output, subject, use case, aspect ratio, and required text or branding.
- Specify composition, subject placement, lens/camera perspective, lighting, palette, materials, atmosphere, and detail level.
- State identity or product features that must remain consistent and elements that must not change.
- Separate essential constraints from optional stylistic preferences.
- For text-heavy graphics, verify spelling and layout; use editable design tools when exact typography is essential.
- For edits, describe exactly what changes and what must remain untouched.
- Respect consent, likeness rights, trademarks, and safety constraints.
Deliver a production-ready prompt, negative constraints where useful, and a review checklist. Do not imply a prompt guarantees pixel-perfect results.
