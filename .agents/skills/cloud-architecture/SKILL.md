# Cloud Architecture
- Gather workload, traffic, latency, compliance, data residency, budget, and availability needs.
- Choose managed services where they reduce operational burden without creating unacceptable lock-in.
- Define network boundaries, identity, secrets, encryption, and least-privilege access.
- Plan stateless compute, durable storage, backups, scaling, and disaster recovery.
- Model failure domains, health checks, observability, and incident response.
- Estimate costs with explicit assumptions and identify cost guardrails.
- Document infrastructure as code and safe change/rollback procedures.
Deliver architecture diagram, trade-offs, security controls, cost assumptions, and recovery plan.
