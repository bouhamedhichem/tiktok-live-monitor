# Build complete full-stack web applications

## When to use
Use for end-to-end websites with frontend, backend, database, authentication, and deployment.

## Recommended workflow
1. Clarify users and workflows.
2. Define architecture and API contracts.
3. Build accessible responsive UI.
4. Implement server-side validation and authorization.
5. Model database and migrations.
6. Add tests.
7. Configure observability.
8. Deploy preview then production with rollback..

## Security, quality, and responsible-use requirements
- Never trust client-side validation or expose secrets in frontend bundles.
- Use least privilege, secure secret storage, and server-side authorization.
- Add tests for normal, invalid, boundary, failure, and recovery scenarios.
- Keep source data, assumptions, versions, and generated outputs traceable.
- Document deployment, monitoring, maintenance, rollback, and known limitations.

## Expected deliverables
- Scope, requirements, architecture, and implementation plan.
- Reusable code/configuration patterns and dependency notes.
- Validation and test evidence, including known gaps.
- Operator documentation and handover checklist.
