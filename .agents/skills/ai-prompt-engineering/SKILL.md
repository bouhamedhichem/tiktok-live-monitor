# AI Prompt Engineering
1. Define task, user, context, output format, constraints, and success criteria.
2. Separate trusted instructions from untrusted user content and retrieved data.
3. Provide concise context, explicit requirements, examples only when they clarify behavior, and a defined fallback for missing information.
4. For structured output, specify schema and validate the result programmatically.
5. For image/video prompts, describe subject, composition, camera, lighting, motion, style attributes, aspect ratio, and exclusions.
6. Test representative, ambiguous, adversarial, and edge-case inputs.
7. Evaluate factuality, consistency, safety, latency, and cost; version prompts and record changes.
Do not assume prompt wording guarantees exact output. Never place secrets or private data in prompts unnecessarily.
Deliver prompt template, test cases, evaluation rubric, and known limitations.
