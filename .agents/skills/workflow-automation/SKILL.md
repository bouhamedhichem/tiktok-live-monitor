# Workflow Automation
1. Map trigger, inputs, steps, outputs, owners, and failure paths.
2. Prefer supported APIs and event/webhook integrations over brittle UI automation.
3. Validate payloads, authenticate requests, and verify webhook signatures.
4. Add idempotency, deduplication, retries with backoff, and dead-letter handling.
5. Protect secrets and personal data; request approval for consequential actions.
6. Add run history, alerts, rate-limit handling, and manual recovery.
7. Test duplicate events, partial failures, timeouts, and schema changes.
Deliver workflow diagram, integration contracts, failure policy, and test checklist.
