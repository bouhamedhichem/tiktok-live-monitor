# Thumbnail Design
1. Identify the exact video promise and the strongest truthful visual moment.
2. Create a single focal point, clear hierarchy, expressive but authentic subject framing, and strong contrast.
3. Keep copy short; thumbnail text should complement rather than repeat the title.
4. Design for small-screen legibility and safe cropping; test at actual thumbnail size.
5. Specify layout, subject placement, background, lighting, typography, color, and optional graphic accents.
6. Provide alternate concepts for testing and explain what variable differs.
Do not use deceptive imagery, fabricated reactions, or false claims. Respect image rights and likeness permissions.
Deliver concept, composition spec, text, palette, typography, and export dimensions for the requested platform.
