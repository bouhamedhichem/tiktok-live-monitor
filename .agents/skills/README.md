# Repository Agent Skills

Portable Agent Skills stored in the standard SKILL.md format.

## Video, social, and creative
- motion-video-production: storyboards, motion direction, edit plans, export checks.
- short-form-video-editing: vertical edits, captions, pacing, and quality checks.
- tiktok-content: TikTok concepts, scripts, captions, and publishing packages.
- instagram-content: Reels, Stories, carousels, profile visuals, and copy.
- youtube-content: YouTube long-form, Shorts, channel strategy, scripts, and packaging.
- thumbnail-design: YouTube thumbnails and social video covers.
- visual-brand-design: brand systems, social templates, and visual guidelines.
- three-dimensional-design: 3D assets, scenes, materials, animation, and rendering.
- image-generation-art-direction: detailed image prompts and visual direction.

## Web, mobile, and product design
- web-design: responsive website and dashboard design.
- ui-ux-product-design: user journeys, wireframes, and interaction design.
- motion-ui-animation: web UI transitions and motion systems.
- react-frontend-engineering: React components, state, routing, and tests.
- android-java-development: native Android apps with Java, XML, and Gradle.
- mobile-app-architecture: mobile architecture, offline data, lifecycle, and navigation.
- localization-i18n: multilingual and right-to-left application support.
- web-accessibility: semantic HTML, keyboard access, and accessibility audits.

## Software engineering and infrastructure
- website-development: full-stack implementation, testing, security, and deployment.
- python-engineering: Python apps, scripts, packages, typing, and tests.
- backend-api-engineering: API design, validation, auth, and observability.
- api-integration-engineering: third-party APIs, webhooks, and resilient integrations.
- database-engineering: schemas, SQL, migrations, indexes, and backups.
- software-testing-qa: unit, integration, E2E, and regression testing.
- cybersecurity-review: threat modeling and secure application reviews.
- devops-ci-cd: pipelines, secrets, deployment, monitoring, and rollback.
- cloud-architecture: secure, scalable cloud systems and cost planning.
- performance-optimization: measured application and database performance work.
- workflow-automation: event-driven workflows, webhooks, and scheduled automation.
- technical-documentation: READMEs, API guides, architecture records, and runbooks.

## AI, data, and connected systems
- ai-agent-development: tool-using agents, approval boundaries, and evaluation.
- ai-prompt-engineering: prompt design, structured workflows, and testing.
- machine-learning-engineering: reproducible training, evaluation, deployment, and monitoring.
- computer-vision: image/video classification, detection, segmentation, and tracking.
- data-science-analysis: exploratory analysis, statistics, and reproducible reporting.
- analytics-data-visualization: metrics, dashboards, and evidence-based insights.
- iot-embedded-systems: sensors, firmware, gateways, and cloud ingestion.

## Growth, research, and product
- seo-content: search intent, content optimization, and technical SEO.
- product-management: requirements, roadmaps, prioritization, and acceptance criteria.
- research-fact-checking: source evaluation, verification, and evidence-based summaries.

Agent clients supporting Agent Skills can discover each skill at .agents/skills/<skill-name>/SKILL.md. These are instruction packs, not editing applications, paid assets, API credentials, or automatic access to social-media accounts. Actual generation, editing, publishing, and deployment still require suitable tools, permissions, and services.
