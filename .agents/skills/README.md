# Repository Agent Skills

Portable Agent Skills stored in the standard SKILL.md format.

## Video and social content
- motion-video-production: storyboards, motion direction, edit plans, export checks.
- short-form-video-editing: vertical edits, captions, pacing, and quality checks.
- tiktok-content: TikTok concepts, scripts, captions, and publishing packages.
- instagram-content: Reels, Stories, carousels, profile visuals, and copy.
- youtube-content: YouTube long-form, Shorts, channel strategy, scripts, and packaging.
- thumbnail-design: YouTube thumbnails and social video covers.

## Design and frontend
- visual-brand-design: brand systems, social templates, and visual guidelines.
- web-design: responsive website and dashboard design.
- ui-ux-product-design: user journeys, wireframes, interaction design, and handoff.
- motion-ui-animation: web UI transitions and motion systems.
- react-frontend-engineering: React components, state, routing, and frontend tests.
- web-accessibility: semantic HTML, keyboard access, screen readers, and WCAG-oriented audits.

## Engineering and operations
- website-development: full-stack implementation, testing, security, and deployment.
- backend-api-engineering: API design, validation, auth, authorization, and observability.
- database-engineering: schemas, SQL, migrations, indexes, transactions, and backups.
- software-testing-qa: unit, integration, E2E, regression, and exploratory testing.
- devops-ci-cd: pipelines, secrets, deployments, observability, and rollback.

## Growth, data, and AI
- seo-content: search intent, content optimization, and technical SEO.
- analytics-data-visualization: metric design, analysis, dashboards, and insights.
- ai-prompt-engineering: reliable prompts, structured workflows, and evaluation.

Agent clients supporting Agent Skills can discover each skill at .agents/skills/<skill-name>/SKILL.md. These files are instruction packs, not editing applications, paid assets, API credentials, or automatic access to social-media accounts. Actual generation, editing, publishing, and deployment still require suitable tools, permissions, and services.
