# IoT and Embedded Systems
1. Define sensors, ranges, sampling rates, environment, power, connectivity, and safety constraints.
2. Specify device firmware, calibration, timestamps, buffering, and offline behavior.
3. Design authenticated device identity and encrypted transport; rotate credentials safely.
4. Define message schema, units, quality flags, sequence IDs, and versioning.
5. Plan gateway/cloud ingestion, retries, duplicate handling, and device provisioning.
6. Test sensor accuracy, disconnections, noisy signals, power loss, and firmware updates.
7. Keep safety-critical control independent of unvalidated cloud predictions.
Deliver architecture, protocol/schema, device test plan, and operational checklist.
