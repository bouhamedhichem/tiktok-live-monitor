# Analytics and Data Visualization
- Clarify the decision the analysis should support and define each metric precisely.
- Inspect data quality, missingness, duplicates, time zones, sampling, and possible bias.
- Distinguish counts, rates, averages, medians, cohorts, and denominators.
- Choose charts that match the question; label units, time ranges, sources, and uncertainty.
- Avoid misleading axes, unsupported causal claims, and unnecessary visual clutter.
- Protect personal data and aggregate or redact sensitive fields.
- Provide reproducible calculations and explain limitations.
Deliver metric definitions, cleaned-data assumptions, charts/dashboard spec, findings, and recommended next steps.
