# Computer Vision
- Clarify image source, labels, environment, camera constraints, latency, and deployment hardware.
- Inspect annotation quality, class balance, privacy, and train/validation/test separation.
- Choose task and model based on accuracy, speed, explainability, and edge constraints.
- Evaluate per-class precision/recall, confusion patterns, localization quality, and robustness.
- Test lighting, viewpoint, occlusion, compression, and domain shift.
- Optimize preprocessing and inference only after measuring bottlenecks.
- Protect faces and sensitive imagery; define retention and consent requirements.
Deliver data plan, model approach, evaluation protocol, deployment design, and limitations.
