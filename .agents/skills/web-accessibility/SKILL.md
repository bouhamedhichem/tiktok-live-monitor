# Web Accessibility
- Use semantic landmarks, logical headings, descriptive links, and native controls.
- Ensure all functionality works by keyboard with visible focus and no keyboard traps.
- Associate form labels, instructions, errors, and status messages programmatically.
- Provide meaningful alternative text; mark decorative imagery appropriately.
- Check text and non-text contrast, zoom/reflow, touch target size, and responsive layouts.
- Support reduced motion and avoid flashing content.
- Use ARIA only when native HTML semantics are insufficient; ensure names, roles, and states are correct.
- Test with automated tools plus manual keyboard and screen-reader checks.
Report findings by severity with location, impact, and actionable remediation. Do not claim WCAG conformance from automated scans alone.
