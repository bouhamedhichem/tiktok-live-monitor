# Icon System Design

## Purpose
Build consistent icon families with grid, stroke, size, and accessibility rules.

## Workflow
1. **Clarify the brief.** Confirm audience, purpose, source material, language, deliverable format, dimensions, deadline, and acceptance criteria.
2. **Inspect inputs.** Use supplied files, data, brand rules, templates, and references. Identify missing facts and never fabricate measurements, citations, credentials, or project results.
3. **Plan the structure.** Create a concise outline, asset list, production sequence, and review checkpoints before producing the deliverable.
4. **Produce consistently.** Apply a coherent visual or document system, reusable styles, accessible hierarchy, and appropriate technical standards.
5. **Validate.** Check factual accuracy, spelling, units, labels, alignment, readability, licensing, file integrity, and output-specific requirements.
6. **Deliver transparently.** Provide editable source where possible, final export, assumptions, limitations, and reproducible steps.

## Quality checklist
- The result matches the brief and requested format.
- All supplied facts and source references are preserved accurately.
- Typography, spacing, contrast, and hierarchy are consistent.
- Images, fonts, models, and other assets have appropriate usage rights.
- Technical output opens or compiles successfully when a suitable tool is available.
- No test, render, compilation, or compliance check is claimed unless it was actually performed.

## Safety and integrity
Protect private information and credentials. Clearly distinguish illustrative or generated content from documentary evidence. Ask before making irreversible changes or publishing externally.
