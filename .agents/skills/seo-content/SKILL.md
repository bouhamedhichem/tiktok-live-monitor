# SEO Content
- Establish search intent, target audience, geography, language, and conversion goal.
- Research keywords using current reliable sources when web access is available; distinguish measured data from hypotheses.
- Map one primary intent to each page and prevent keyword cannibalization.
- Create useful titles, descriptions, headings, internal links, image alt text, and structured content.
- For technical SEO, review crawlability, indexability, canonical URLs, sitemap, robots rules, redirects, performance, and mobile usability.
- For video SEO, align title, description, captions, chapters, and thumbnail with the actual content.
Avoid keyword stuffing, doorway pages, link schemes, fake reviews, and guaranteed ranking claims.
Deliver keyword map, page brief, metadata, content outline, and prioritized technical checklist.
