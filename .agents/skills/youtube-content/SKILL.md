# YouTube Content Strategy
- Define channel niche, target viewer, content pillars, format, language, and viewer promise.
- Build repeatable series and a realistic publishing cadence based on production capacity.
- Write scripts with a compelling opening, clear structure, visual examples, pattern changes, and satisfying payoff.
- For Shorts, optimize for vertical framing, immediate context, captions, and a concise ending.
- For long-form, plan chapters, retention beats, B-roll, graphics, and transitions.
- Prepare title options, thumbnail concept, description, chapters, tags only when relevant, pinned comment, and CTA.
- Evaluate impressions, click-through rate, retention, returning viewers, and audience feedback without fabricating results.
- Never promise virality or use misleading titles/thumbnails. Use licensed media and disclose sponsorships.
Deliver a complete video brief, script, packaging, and measurement plan.
