# Performance Optimization
1. Establish user-facing performance goals and baseline measurements.
2. Profile the actual bottleneck before changing code.
3. Examine network waterfalls, bundle size, rendering, API latency, database plans, and resource use.
4. Optimize the highest-impact bottleneck and preserve correctness.
5. Use caching with explicit invalidation, freshness, and privacy rules.
6. Benchmark realistic workloads and compare before/after results.
7. Add performance budgets and regression monitoring.
Do not claim faster performance without measurements. Report test environment, workload, and trade-offs.
