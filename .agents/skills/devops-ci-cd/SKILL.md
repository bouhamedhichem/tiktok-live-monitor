# DevOps and CI/CD
1. Inspect repository workflows, build commands, environments, deployment platform, and secret management.
2. Create repeatable pipelines for install, lint, typecheck, tests, build, and security checks.
3. Pin runtime/tool versions and use lockfiles and reproducible builds.
4. Keep secrets in platform secret stores; never print or commit them.
5. Separate preview, staging, and production configuration and data.
6. Add health checks, deployment verification, logs, alerts, and rollback instructions.
7. Use least privilege and review permissions for tokens and service accounts.
Do not promote to production without explicit authorization and verified checks. Clearly report deployment status and blockers.
