# Web Design
Identify product purpose, users, tasks, content, brand, reference sites, devices, accessibility needs, and success criteria.
1. Map user journeys and information architecture before styling.
2. Define tokens for colors, typography, spacing, radii, elevation, breakpoints, and interaction states.
3. Establish page hierarchy, navigation, content density, and responsive behavior.
4. Design loading, empty, error, success, disabled, and focus states.
5. Use semantic components, accessible contrast, labels, keyboard navigation, and reduced-motion support.
6. Check narrow mobile, tablet, and desktop widths.

Build a coherent system, not isolated screens. Keep primary actions obvious. Avoid fake metrics, fake testimonials, and nonfunctional controls. Deliver page map, component inventory, tokens, responsive rules, interaction specs, and acceptance checklist.
