# Data Science Analysis
1. Translate the question into measurable hypotheses and analysis steps.
2. Inspect schema, units, missing values, duplicates, outliers, sampling, and provenance.
3. Visualize distributions and relationships before modeling.
4. Choose statistical methods that match assumptions and study design.
5. Avoid leakage, p-hacking, and causal claims from observational correlations.
6. Report uncertainty, limitations, and reproducible code.
7. Protect personal and confidential data.
Deliver data-quality summary, analysis, charts, findings, and caveats.
