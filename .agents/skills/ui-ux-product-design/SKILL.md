# UI/UX Product Design
1. Define users, jobs-to-be-done, constraints, accessibility needs, and product success measures.
2. Map key journeys, entry points, decision points, and failure/recovery paths.
3. Create information architecture and low-fidelity wireframes before visual polish.
4. Specify form behavior, validation, empty/loading/error/success states, navigation, and feedback.
5. Validate with realistic tasks and usability heuristics; separate assumptions from observed findings.
6. Hand off component states, responsive behavior, content rules, and acceptance criteria.
Prioritize clarity, consistency, accessibility, and user control. Avoid dark patterns and unnecessary friction.
