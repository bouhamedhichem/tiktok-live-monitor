# Video Color Grading

## Workflow
1. Define the audience, business goal, scope, constraints, and acceptance criteria.
2. Inspect source assets, data, platform versions, repository conventions, and dependencies.
3. Plan architecture, composition, data contracts, delivery formats, and quality metrics.
4. Build incrementally using reusable components and reproducible settings.
5. Validate accuracy, accessibility, performance, compatibility, and rights/provenance.
6. Test edge cases, device sizes, failure paths, and realistic workloads.
7. Review against source evidence and stakeholder expectations; iterate on defects.
8. Package outputs with source files, documentation, monitoring, and maintenance notes.

## Guardrails
- Respect intellectual property, licenses, privacy, and platform terms.
- Never fabricate source data, citations, metrics, or approvals.
- Protect credentials and sensitive records; use least privilege.
- Label synthetic, delayed, estimated, or generated outputs clearly.

## Deliverables
- Scope and design/architecture plan.
- Working implementation and reusable assets.
- Test and quality-control evidence.
- Export/publishing instructions and maintenance notes.
