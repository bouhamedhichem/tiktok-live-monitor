# Mobile App Architecture
- Identify platform, language, UI framework, supported OS versions, and product flows.
- Separate presentation, domain logic, data access, and platform integrations.
- Model navigation, state restoration, lifecycle, permissions, and deep links.
- Design offline-first behavior, local persistence, synchronization, and conflict handling when needed.
- Secure tokens and local data; avoid storing secrets in source code.
- Add accessibility, localization, responsive layouts, and crash reporting.
- Test lifecycle events, network loss, upgrades, and device diversity.
Deliver architecture, module boundaries, data flow, and verification plan.
