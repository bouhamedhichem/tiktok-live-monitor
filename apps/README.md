# Portfolio applications

| Application | Directory / Vercel root | Purpose |
|---|---|---|
| NexusERP | `apps/nexus-erp` | ERP, CRM, inventory and analytics |
| QuantVision AI | `apps/quantvision-ai` | Commodity research and paper trading |
| SentinelAI | `sentinel-ai/frontend` | Industrial monitoring and incident console |

Each frontend has its own Vite package and can be configured as a separate Vercel project with its directory as Root Directory. Existing TikTok Monitor root/frontend/backend sources are untouched. Read each application README for its run commands, feature scope, data limitations and next milestones.
